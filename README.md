# 🍰 甜甜小厨房 · 卡哇伊学做菜小程序

一个**教人做菜**的 H5 小程序（网页版小程序，手机浏览器打开就是小程序的样子）。
甜甜粉紫配色、圆鼓鼓的卡片、会飘的小爱心 Emoji——小女生会喜欢的风格 💕

> 双击 `index.html` 就能打开，不需要装任何东西、不需要联网服务器。

---

## ✨ 三个核心玩法

### 1️⃣ 看图点菜 → 一道菜有多种做法视频
- 首页 / 分类榜单里点任意一道菜的**图片卡片**
- 进入菜品页：耗时、难度、热量、食材清单、分步做法、小贴士
- 最下面就是 **「这菜有 N 种做法」**：
  - 每种做法一张卡片（比如「经典日式卷法」「空气炸锅版」「不炒糖色懒人版」）
  - 卡片上 5 个按钮：**哔哩哔哩 / 抖音 / 西瓜视频 / YouTube / 小红书**
  - **点一下就跳到那个网站，直接免费播放教学视频**（不是本站自己塞视频，所以永远免费、不用充会员）
  - 想加**站内直接播放**：在做法里加 `bv: 'BV1xx411c7XX'` 字段，就会出现 B 站播放器内嵌框

### 2️⃣ 🧪 魔法厨房 —— 拖食材进锅，组合出一道菜
- 底部导航第 2 个 tab
- **把食材从下面的「食材抽屉」拖进锅框**（手机上直接点一下也能加进去，锅最多 6 样）
- 锅上方会**实时猜**「✨ 好像会变成：番茄炒蛋」
- 点 **🔥 开始烹饪** 弹出结果：
  - **🎉 完美复刻**：食材刚好命中菜谱
  - **💡 创意改良版**：命中大部分，会告诉你差了什么
  - **🪄 神秘料理诞生**：完全没见过的搭配，自动给你编一套步骤 + 帮你搜同款教学视频
- 27 种组合菜谱（番茄炒蛋、麻婆豆腐、宫保鸡丁、酸辣汤、提拉米苏、咖喱鸡…）都能靠拖拽做出来
- 底部还有「📖 组合菜谱手册」，点一下直接把食材塞进锅

### 3️⃣ 💖 收藏 / 我的
- 菜品卡片右上角 🤍 一点就收藏
- 「我的」里有：收藏小本本、魔法厨房创作记录、8 个勋章（收集够会亮起来）
- 数据存在浏览器本地，关掉再打开还在

## ✏️ 怎么加菜（超简单，复制粘贴就行）

打开 `js/data-dishes-1.js`（或 2/3），照着抄一段：

```js
{
  id: 'd123', n: '菜名', e: '🍳', c: 'home',      // c 是分类 id
  t: 15, lv: '简单', kcal: 320, sv: 2,          // 耗时/难度/热量/份量
  likes: 28640, au: '小桃', ae: '🍑',
  d: '一句话简介',
  tags: ['下饭', '快手', '新手友好'],
  bg: ['#FFB3A0', '#F2744F'],                    // 封面渐变色
  ing: ['番茄', '鸡蛋', '小葱'],                 // 写进食材库的名字才能被拖拽
  steps: ['第一步…', '第二步…', '第三步…'],
  tips: '小贴士',
  ms: [                                          // ← 多种做法 = 多个视频入口
    { n: '做法一的名字', d: '亮点描述', q: '搜索关键词' },
    { n: '做法二的名字', d: '亮点描述', q: '搜索关键词' }
  ]
}
```

- **一个 emoji 不足以表达这道菜？** 加 `art` 字段，摆多个会自动缩小排进盘子里：
  ```js
  { n: '小笼包', e: '🥠', art: '🥠🥠🥠' }      // 一行摆三个
  { n: '拼盘',   e: '🍽️', art: '🥠🥠+🥠🥠' }   // 用 + 分行，摆成一堆
  ```
  （`e` 用于文字场合，`art` 用于盘子里的「图片」；不写 `art` 就用 `e`）

- 分类 `c` 可选：`breakfast 早餐` `staple 主食` `home 家常` `meat 荤菜` `veg 素菜` `soup 汤羹` `cold 凉菜` `sweet 甜品` `drink 饮品`
- 想加新分类：在 `data-dishes-1.js` 顶部的 `KITCHEN_CATS` 里加一条就行
- 想加新食材：在 `data-kitchen.js` 的 `KITCHEN_ING` 里加 `{ n: '香菜', e: '🌿', c: 'veg', t: ['香'] }`
- `c`（食材分类）可选：`veg 蔬菜` `meat 肉蛋` `aqua 水产` `dry 主食` `dairy 乳品` `fruit 水果` `spice 调料` `bake 烘焙`

### 换成自己的视频链接
现在是**搜索页跳转**（最稳、永远免费、不会失效）。
如果你有指定的视频，在 `q` 旁边加 `url` 字段即可（代码里已支持，改 `PLATFORMS` 那一行也行）：

```js
{ n: '我的做法', d: '我收藏的教程', q: '番茄炒蛋', url: 'https://www.bilibili.com/video/BV1xx411c7XX' }
```

## 📱 怎么在手机上玩

1. 最简单：把这个文件夹拷到手机，用浏览器打开 `index.html`
2. 或者电脑上装个 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 跑 H5
3. 电脑上想边改边看：在这个文件夹里执行 `python -m http.server 8777`，然后开 `http://localhost:8777`

> 想改成**真正的微信小程序**：把 `data-*.js` 的数据原样搬进 `pages/xxx/data.js`，
> 卡片/列表结构照着写 `wxml`，`<div class="card">` → `<view class="card">`，
> `<a href>` → `<navigator url>`（或直接 `wx.openEmbeddedMiniProgram` / `web-view` 打开 B 站页面），
> 拖拽那部分换成 `movable-area + movable-view` 即可，数据完全不用改。

## 🎀 设计说明（卡哇伊在哪）

- 主色：奶粉 `#FF7EB6` + 薰衣草 `#B79CF0`，奶油黄 / 薄荷绿点缀
- 圆角超大（24–30px）、描边是**虚线糖果边**、按钮下面有 3px 实心「按压块」
- 菜品「图片」= 渐变色盘子 + 大 Emoji + 会一闪一闪的 ✨🌟💫
- 加菜/收藏/烹饪成功会撒 Emoji 彩带（💕✨🎀🧁）
- 锅里有食材时会冒蒸汽 ♨️，爱心 Emoji 在背景飘
- 手机上左右滑切分类，长按拖食材；电脑上鼠标直接拖
